# Capstone: Production Agent Design Template

**Course lessons:** Lesson 48 — "Capstone Brief", Lesson 49 — "Capstone Walkthrough"
**Folder:** `capstone-template/`

Your capstone deliverable is a **10-part production design document** for one
real business process in your organization. Copy
`capstone-design-template.md`, fill in each section, and you will leave the
course with a plan you can execute on Monday morning.

## The 10 parts (and which course section each maps to)

| # | Part | Course section |
|---|------|----------------|
| 1 | Business case & ROI | S1 — The Enterprise Case |
| 2 | Workflow map | S3 — Agent Workflows |
| 3 | Agent architecture | S2 — Anatomy of an Agent |
| 4 | RAG & memory design | S4 — Enterprise Knowledge |
| 5 | Tool contracts | S5 — Tools, APIs, MCP |
| 6 | Multi-agent design (if applicable) | S6 — Multi-Agent Systems |
| 7 | Eval plan | S7 — Evaluating Agents |
| 8 | Cost model | S8 — Cost Engineering |
| 9 | Governance & security | S9 — Governance, Security, Compliance |
| 10 | UX & rollout plan | S10–S11 — Human-Agent UX, Pilot to Production |

## Worked example (Lesson 49)

The template includes a worked example throughout: an **invoice-exception
handling agent for a finance team** — business case with ROI numbers,
architecture, RAG design, tool contracts, evals, cost model, guardrails,
governance, UX, and phased rollout. Copy what fits, change what doesn't.

## Grading rubric — what "production-ready" means

Each part is scored 0–2:
- **0 — missing:** the part is absent or hand-wavy.
- **1 — draft:** the part exists but has unanswered questions a security
  review or executive sponsor would ask.
- **2 — production-ready:** the part would survive a real architecture
  review, security review, and budget review.

**Pass mark: 14/20.** Anything scoring 0 must be fixed before the design
counts as complete.

## How to use this template

1. Copy `capstone-design-template.md` to `my-capstone-<process>.md`.
2. Fill in parts 1–2 first (business case + workflow) — if these are weak,
   stop and pick a better process (Lesson 5's use-case framework).
3. Fill in the rest section by section as you finish each course module.
4. Self-grade with the rubric above, then ask a colleague to red-team it.
